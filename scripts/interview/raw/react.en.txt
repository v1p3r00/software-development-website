### Q1
LEVEL: junior
TOPIC: JSX & rendering
TYPE: output
QUESTION: What does the following React component render?
CODE:
function App() {
  const name = "Anna";
  return <h1>Hello, {name}!</h1>;
}
ENDCODE
A) Hello, name!
B) Hello, Anna!
C) Hello, {name}!
D) It throws an error because variables cannot be used in JSX.
ANSWER: B
EXPLANATION: Curly braces in JSX allow JavaScript expressions to be evaluated, so the value of the `name` variable, `Anna`, is inserted into the `<h1>` element. The common incorrect answer is tempting because JSX initially looks like HTML, but it is actually syntax that integrates JavaScript expressions.
###END
