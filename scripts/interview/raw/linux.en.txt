### Q1
LEVEL: junior
TOPIC: Filesystem hierarchy
TYPE: theory
QUESTION: On a Linux system, you want to place a system-wide configuration file that is used by multiple applications and administrative tools. Which directory is the most appropriate location for general system configuration?
A) /etc
B) /opt
C) /var
D) /srv
ANSWER: A
EXPLANATION: The `/etc` directory is the conventional location for system-wide configuration files. `/opt` is used for optionally installed software, `/var` for variable data, and `/srv` for data served by system services. `/opt` may be tempting because it often contains application-related files, but it is not the standard location for general system configuration.
###END

### Q2
LEVEL: junior
TOPIC: Permissions & ownership
TYPE: output
QUESTION: What will be the result of the following commands on a typical Linux system?
CODE:
touch report.txt
chmod 640 report.txt
ls -l report.txt
ENDCODE
A) -rw-r----- 1 ... report.txt
B) -rwxr----- 1 ... report.txt
C) -rw-r--r-- 1 ... report.txt
D) -rw------- 1 ... report.txt
ANSWER: A
EXPLANATION: The `640` permission mode gives the owner `rw-`, the group `r--`, and others `---`. Therefore, the permission bits are `-rw-r-----`. The `640` mode is a common interview trap because it is easy to overlook the group's read permission.
###END

### Q3
LEVEL: junior
TOPIC: Users & groups
TYPE: behavior
QUESTION: After creating a user, you want the new user to have a dedicated primary group with the same name. Which command ensures this on a typical Linux system?
A) useradd -G alice alice
B) useradd -g users alice
C) useradd -m alice
D) useradd -U alice
ANSWER: D
EXPLANATION: `useradd -U alice` creates a group for the new user and assigns it as the user's primary group. `-G` manages supplementary groups, `-g users` would set an existing group as the primary group, and `-m` controls creation of the home directory. `-m` may be tempting because creating a home directory is also commonly needed when creating a user, but it does not control group creation.
###END

### Q4
LEVEL: junior
TOPIC: Processes & signals
TYPE: behavior
QUESTION: A running process has PID 1234. Which command sends it a normal termination signal that allows the process to shut down gracefully?
A) kill -9 1234
B) kill 1234
C) kill -STOP 1234
D) kill -KILL 1234
ANSWER: B
EXPLANATION: `kill 1234` sends `SIGTERM` by default, allowing the process to handle the termination request and perform cleanup. `SIGKILL` causes immediate termination and cannot be handled, while `SIGSTOP` suspends the process. `kill -9` may be tempting because it reliably terminates a stuck process, but in production, `SIGTERM` is generally the appropriate first choice.
###END

### Q193

QUESTION: In a Bash script, you want to run multiple commands so that the script proceeds only if the previous command succeeds. Which solution expresses this directly in a single command line?
A) `command1 && command2`
B) `command1 || command2`
C) `command1 ; command2`
D) `command1 & command2`
ANSWER: A
EXPLANATION: The `&&` operator runs the second command only if the first succeeds, meaning it returns a zero exit status. `||` runs the second command when the first command fails, the semicolon does not make the second command dependent on the success of the first, and `&` runs the first command in the background.
