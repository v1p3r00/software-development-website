### Q1
LEVEL: junior
TOPIC: SELECT & filtering
TYPE: output
QUESTION: What will the following query return in PostgreSQL?
CODE:
SELECT name
FROM employees
WHERE salary > 1000000;
ENDCODE
A) Only the names of employees whose salary is greater than 1,000,000
B) The names of employees whose salary is at least 1,000,000
C) All employee names, then filters by salary
D) An error because WHERE cannot be used with a numeric value
ANSWER: A
EXPLANATION: `>` means strictly greater than, so only employees with a salary above 1,000,000 are returned. `>=` would also include a salary of exactly 1,000,000. The common wrong answer is tempting because it is easy to confuse `>` with `>=` in an interview setting.
###END
