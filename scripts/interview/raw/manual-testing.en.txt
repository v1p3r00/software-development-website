### Q1
LEVEL: junior
TOPIC: Testing fundamentals (ISTQB)
TYPE: scenario
QUESTION: In an e-commerce application, a user successfully adds a product to the cart, but the cart icon still shows 0. The tester can reproduce the problem. What is the most important first step?
A) Immediately fix the problem in the development environment
B) Report the defect with reproduction steps and the actual/expected results
C) Check whether the defect occurs only in Chrome and do not report it until then
D) Wait for the next release because UI defects are generally low priority
ANSWER: B
EXPLANATION: A reproducible defect should be documented with sufficient evidence so that the developer can reliably investigate it. Reproduction steps, the actual result, and the expected result are essential defect-report information. Immediate fixing is not the tester's responsibility, and checking additional environments may be useful but is not a prerequisite for reporting a clear defect. The most tempting wrong answer is waiting because some UI defects really can be less critical, but severity and priority should not be assumed automatically.
###END

### Q2

A) Only after the developer has finished coding
B) Only at the end of the sprint, when all functionality is complete
C) Already when the requirements and acceptance criteria are being discussed
D) Only after the release candidate has been created
ANSWER: C
EXPLANATION: Early tester involvement helps identify ambiguous or incomplete requirements and improves testability while reducing the cost of finding defects later. The most tempting wrong answer is getting involved only after development because testing is often viewed as checking already-completed software, whereas in modern development testing is a continuous activity.

### Q3

B) The search does not define the user's role
C) The requirement can only describe frontend behavior
D) "Quickly" is not an objective and measurable expectation
ANSWER: D

The most tempting wrong answer is focusing on the browser or user role because those can be important test conditions in other cases, but the most direct problem here is that the expectation is not measurable.

B) System testing

D) Integration testing
ANSWER: A

The most tempting wrong answer is integration testing because interactions between components are also important, but an isolated component is the subject of unit testing.

### Q5

QUESTION: An age field accepts integers from 18 through 65, inclusive. Which test set reasonably checks the boundary values?
A) 18, 19, 64, 65
B) 17, 18, 65, 66
C) 16, 20, 60, 70
D) 1, 18, 65, 100
ANSWER: B
EXPLANATION: With Boundary Value Analysis, values around the boundaries should be tested: just below the minimum, the minimum, the maximum, and just above the maximum. Here these are 17, 18, 65, and 66. The most tempting wrong answer is testing only the allowed boundary values because they are explicitly specified, but defects around boundaries often occur precisely at the invalid neighboring values.
