### Q1
LEVEL: junior
TOPIC: Java Core & OOP
TYPE: behavior
QUESTION: Mi történik az alábbi kódban, amikor a `Dog` objektumon meghívjuk a `makeSound()` metódust?
CODE:
class Animal {
    void makeSound() {
        System.out.println("animal");
    }
}

class Dog extends Animal {
    @Override
    void makeSound() {
        System.out.println("dog");
    }
}

Animal animal = new Dog();
animal.makeSound();
ENDCODE
A) Az `animal` szöveg jelenik meg, mert a változó típusa `Animal`.
B) A `dog` szöveg jelenik meg, mert a példány tényleges típusa `Dog`.
C) Fordítási hiba történik, mert egy `Animal` referenciából nem hívható a `Dog` metódusa.
D) Futásidejű `ClassCastException` történik.
ANSWER: B
EXPLANATION: A metódusok felülírása esetén Java dinamikus kötést használ. A referencia deklarált típusa `Animal`, de az objektum tényleges típusa `Dog`, ezért futáskor a `Dog.makeSound()` kerül meghívásra. A gyakori téves válasz azért csábító, mert a referencia deklarált típusa valóban `Animal`, de ez nem határozza meg az override-olt példánymetódus futásidejű implementációját.
###END
